## Learning Path

A practical sequence for this collection:

1. **Fog Port Hunt** — start with basic port discovery.
2. **Nmap Recon Relay 2** — build structured Nmap reconnaissance skills.
3. **Foggy Services** — examine discovered services.
4. **Fog Recon Drift** — expand general reconnaissance practice.
5. **Fog Files: Hidden Paths** — investigate hidden web resources.
6. **Fog Trail** — apply enumeration techniques in a CTF workflow.
7. **Fog Trail 2** — continue challenge-based investigation.
8. **Fog Code Sleuth** — add code-analysis skills.
9. **Fog Brute Force** — study authentication-testing concepts in the lab.
10. **Fog Recon to Root** — combine reconnaissance and root-focused reasoning.
11. **NFS LPE Lab: Web to Root** — explore NFS and Linux privilege-focused concepts.
12. **NFS Root Run** — consolidate NFS-focused security analysis.

## How to Use the Labs

* Open each challenge using its direct Learn SecByte URL.
* Review the objective before beginning.
* Start with reconnaissance and record discovered information.
* For Nmap and port-hunt labs, document hosts, ports, and services.
* For web labs, inspect paths and application behavior within the authorized environment.
* For NFS challenges, study exposed resources and Linux permission concepts.
* Keep notes on findings, hypotheses, and lessons learned.
* Use brute-force or other authentication-testing techniques only inside authorized lab environments.
* Treat every challenge as a controlled exercise in security analysis.
